# Cidade, praia, corpo e mãos — validação da entrega

Versão 705.25.3-city-coast-body, revisão 7fe523ee9efe2394. Publicação dpl_3SAXdSsEoRRgupq9KwqjF1dAgfav no endereço https://otthi-world-campanha-teste.vercel.app/games/otthi/. Código: b5a72da3f467a0ae085993d1bf6127bab71b1b08.

A execução completa do GitHub passou: 240 testes, inferência corporal, música, dança, frota, vias, comércio, cinco jogos originais e família. A câmera, os controles por toque, o objeto selecionado e o corpo foram testados nos dois modos de WAR. Os testes de câmera combinam inferência real com imagens oficiais e reprodução corporal sintética, identificadas nos respectivos relatórios.

No endereço público foram conferidos 58 arquivos, compra pelo botão nativo, preservação da família e do Fusca, ondas, os modelos reais de corpo/mãos, ativação da PWA e o APK existente. O relatório public-result.json registra as verificações efetivamente concluídas. O script public-check.mjs pode ser executado a partir da raiz do repositório com Node e Playwright instalados.

Os dados são de perfis locais isolados, sem ler salas ou jogadores reais do Firebase. Telefone físico, precisão com a câmera de um usuário, alto-falante Android e multiplayer real entre dois aparelhos não foram certificados. O APK é o wrapper já existente, que abre a versão web atualizada.
